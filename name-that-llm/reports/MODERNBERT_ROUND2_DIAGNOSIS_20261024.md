# 第二轮弱结果的原因分析与下一方向

2026-10-24。结论：真实管线运行和OOF完整性通过，但冻结通用编码器加LR只获得0.289904 BA；现有证据更支持先改变特征的统计建模方式，而不是把原因归咎于GPU或直接加长文本。这里区分已观察事实与待验证解释。

## 观察到了什么

- 第二轮540/540前向、5/5拟合完成，源码、模型、数据、行序、标签与缓存契约均通过核验，没有发现能解释低分的执行失败。工程成功不等于模型有效。
- 编码器权重冻结，只训练了StandardScaler+LR。它没有利用本任务18类标签调整语言表示；最后4层平均池化虽包含信息，不保证保留最能区分模型写作风格的方向。
- 输入3,072维，每折训练约1,727/1,728条，尺度与协方差估计需要约束。这是高维小样本的建模挑战，不足以单独证明LR过拟合。
- 开发token数中位数134、90分位269、最大396；275/2,159条（12.737%）超过256，仅1条超过384。截断组现有普通准确率35.273%，未截断组28.079%。这不是控制变量实验，两组标签/题目不同；不能据此说截断有益，也不能认定截断已经导致主要损失。

## 表示中的题目结构

按各组质心计算`组间平方差/总平方差`，同时列出随机打乱分组但保持组大小时的期望，以免120个prompt与18个标签的组数差异误导判断：

| 表示与分组 | 观察解释比例 | 随机分组期望 | 校正后的解释比例 |
| --- | ---: | ---: | ---: |
| 原始向量 / prompt | 11.183% | 5.514% | 5.999% |
| 原始向量 / 模型标签 | 0.694% | 0.788% | -0.095% |
| L2归一化 / prompt | 30.763% | 5.514% | 26.722% |
| L2归一化 / 模型标签 | 2.591% | 0.788% | 1.818% |

随机期望为`(组数-1)/(样本数-1)`；校正比例为`1-(1-观察比例)/(1-随机期望)`。负值只表示低于随机质心解释量，不表示负方差。这里没有采用把维度数重复除入自由度的omega公式，也不把两个比例的比值解释成因果效应倍数。

这些数值说明题目结构在向量几何中明显存在；模型类别的简单质心结构较弱。模型信息也可能位于低方差或不同组合方向，因此不能说“没有模型信息”。没有做改变encoder/长度/分类头的控制消融，本分析不能分配低分的因果比例。
