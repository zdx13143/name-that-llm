# Name That LLM CPU 实验结果

记录日期：2026-10-18（Asia/Singapore）。用户恢复任务后，第三轮固定搜索、一次最终留出评估及真实离线 Notebook 复现均已完成。当前无运行中的训练任务。最终冻结配置为 `b316d0a5c48a`：字符 TF-IDF (2,5) + 26 个文体统计特征（权重 0.25）+ LogisticRegression C=16。

| 开发阶段 | 最佳 balanced accuracy | 配置 |
| --- | ---: | --- |
| 初始最好基线 | 0.281513 | 字符 TF-IDF (3,5) + LinearSVC C=1 |
| 第一轮 | 0.295880 | 字符 TF-IDF (2,5) + LogisticRegression C=4 |
| 第二轮 | 0.340799 | 同上 + 文体特征，权重 0.25 |

从初始最好基线到冻结模型，开发 BA 增加 **0.065305（6.53 个百分点）**。这不是独立隐藏测试上的增益估计。自适应配置比较存在选择偏差，下列 bootstrap 区间也不保证榜单收益。

## 后两轮的收益与停止依据

第二轮文体特征相对第一轮最佳模型增加 **0.044919**，按 prompt 配对 bootstrap 95% 区间 **[0.029630, 0.059815]**，5 折均为正向。另两个分组 seed 的增益为 +0.021312 [0.003704, 0.039375] 和 +0.031485 [0.013889, 0.048611]，因此继续了第三轮。第二轮短/边界 n-gram 和独立字符/词 margin 融合均未超过文体增强模型。

第三轮严格执行预先记录的三个批次，始终复用同一开发/留出划分：

| 第三轮方向 | 批次最佳 BA | 相对该批开始时最佳模型的增益 | prompt bootstrap 95% 区间 |
| --- | ---: | ---: | --- |
| style 权重 0.05 /0.1 /0.5 | 0.327836 | -0.012963 | [-0.026389, 0.000008] |
| 保留 style 0.25，LR C=0.25 /1 /16 | 0.346818 | +0.006019 | [-0.002782, 0.014819] |
| 最佳 LR 下短 n-gram，另试 LinearSVC C=1 | 0.343110 | -0.003708 | [-0.014819, 0.006960] |

最终 C=16 相对第二轮 C=4 的累计开发增益也是 +0.006019，区间 [-0.002782, 0.014819]；两次重新分组后排名一致：

| seed | C=16 BA | C=4 BA | 增益及 prompt bootstrap 95% 区间 |
| --- | ---: | ---: | --- |
| 20261019 | 0.340803 | 0.334781 | +0.006022 [-0.000459, 0.012504] |
| 20261020 | 0.338959 | 0.326910 | +0.012049 [0.003693, 0.020394] |

主比较未满足预定的确认提升条件（增益至少 0.005、区间下界 >1e-12、至少三折非负且最差折不低于 -0.05）。三批均无确认提升，全部主/稳定性拟合无收敛警告，因而按既定规则**工程停止并冻结最高开发 BA 配置**。`small_gain_supported_in_tried_batches=false`：累计区间上界仍为 0.014819，不能声称已经证明平台期，也不能排除其他方法继续改善。

第一轮一个特征批的 bootstrap 下界为 3.8e-19，数值上等于零；原始 JSON 的 `confirmed_improvement=true` 不作为稳健正向证据。原始记录和 exact 源码快照保持不变；通用脚本已修为下界必须 >1e-12，并有近零回归测试。修复未改变预测、指标或重跑旧拟合。

实际环境：Python 3.13.2、scikit-learn 1.9.1、numpy 2.5.4、scipy 1.18.1、pyarrow 26.0.0、joblib 1.6.0。Kaggle 预装版本尚未核对，不能把本地复现写成已经在 Kaggle 可运行的验证。
