## 问题与唯一候选

第五轮四视角SVC对照BA .359325，固定80/20融合仅.323681。两者分数尺度不同：SVC平均最高分.0842，第三轮Gaussian .4933。此次仅检验一个改动：各分数来源在训练集内部学习一个正温度，然后仍固定80%风格、20%Gaussian融合。模型配方、原120prompt/2159行、外层五折、编码器与特征均不变；不以外层BA选择温度或权重。

温度缩放参考[Guo等，ICML 2017](https://proceedings.mlr.press/v70/guo17a.html)：用一个正标量缩放分类分数，再softmax。这里把该方法用于SVC margin和Gaussian scores；论文不是本任务有效性的证据。标量缩放不改变单个模型的类别排序，但会改变融合时各模型的影响。当前只是一项待验证假设。

## 严格的嵌套分组

每个外层训练集约96个prompt；仅在其中做3折GroupKFold。每个内层训练折分别拟合原配方SVC和原R3 Gaussian，生成内层未参与拟合样本的原始分数。完成内层OOF后，分别用内层标签最小化平均多类负对数似然，学习两个温度。逆温度beta范围[.05,50]，bounded一维优化，xatol=1e-8，每次最多100个目标函数评估；失败立即停止，不回退到另一值。

外层验证使用已完成R5的五个SVC和R3的五个Gaussian head。先验证模型哈希、重新计算的未校准分数与旧OOF一致，再应用本外层训练集学到的两个温度，固定80/20融合。**旧五折OOF在外层训练行上的预测不能拿来直接学外层温度**：对应模型可能见过当前外层验证题目。必须产生新的内层OOF。温度拟合与验证的行/分组/折身份及原始分数全部保存。

所有变换包括TF-IDF词表/IDF、Gaussian缩放/PCA/协方差只看内层训练折。已冻结且不使用本任务标签更新的R2编码器特征可复用。旧30prompt不评分、不训练、不重划；不下载外部训练池、不推断测试题目分组、不做强制平衡分配。
