## 固定算法与隔离

每折只接收该训练折的特征、标签和prompt_id：

1. 仅训练折计算每维均值/标准差。
2. 从训练向量减去各训练prompt均值，对残差做确定性完整SVD，固定取128个方向；不看验证特征来拟合PCA。
3. 在该子空间中以4轮交替均值估计 `向量 = 类别均值 + prompt偏移 + 残差`。
4. 估计残差协方差（自由度N-G-K+1）和prompt协方差（校正组均值中的残差），使用Ledoit–Wolf收缩；残差相对jitter=1e-8，prompt相对特征值下限1e-4。
5. 将未知新题目的影响积分掉，用共享协方差的18类高斯分数逐行预测，均匀类别先验、温度1。该预测可展开为线性分数，但训练规则不同于上一轮LR。

方法依据还包括scikit-learn官方[判别分析与收缩说明](https://scikit-learn.org/stable/modules/lda_qda.html#shrinkage-and-covariance-estimator)及[Ledoit–Wolf接口](https://scikit-learn.org/stable/modules/generated/sklearn.covariance.LedoitWolf.html)。收缩用于小样本相对高维下稳定协方差估计，不保证本数据改善。

重用第二轮 `features.npz` 和LR `oof.npz`，校验原contract、字节SHA、每行身份、labels、fold_id。两者都是原120个prompt，无旧30个prompt。冻结编码器未学习标签，所以其全开发缓存可以在新折内预处理之前重用；若未来微调编码器就不能照搬此方式。第二轮LR不重新拟合。
