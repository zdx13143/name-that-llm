固定唯一候选：`0.8 * softmax(SVC margin) + 0.2 * Round3 Gaussian scores`。80/20是运行前选择的简单风格主导比例，未用本轮OOF寻优，也未复制队友150-prompt调权。两个分数来源没有联合校准，这是必须实测的风险。单独SVC作为解释融合增益的对照，不是失败后可切换提交的候选。形状视角把连续字母词换成X/x；功能词视角保留固定功能词、标点并把内容词替换为CONTENT，尝试减少题目内容影响。它们也可能丢掉有用信号。

不导入完整大模型集成、外部训练池、旧已用留出、分组中心化、test聚类、Hungarian平衡分配或按公榜分数选择权重。历史原style/partial完整OOF在当前工作区缺失；旧日志中的0.348673只列历史参考，不冒充此次可配对对照。
