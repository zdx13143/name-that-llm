计划日期：2026-10-21；训练前固定。用户已要求“上传完后分析队友的工作，在此基础上继续推进”，并此前授权自主决策。本轮在自己的 `exp/dev-comparison-20261021` 分支执行下述有限 CPU 计划；不更改 main、旧最终模型或旧实验保护记录。

## 问题与验证边界

队友的折内 TF-IDF、手工指纹和 prompt GroupKFold 可以复用。现有融合分数并未隔离完整的超参数/权重选择过程；嵌入增量对照重复加入了当前视图。先修复可确定的实现错误，再用共同协议重新比较双方的轻量方案。

- 只使用旧 `cpu_round3/split_manifest.json` 固定的 **120 prompt / 2,159 行开发数据**。训练 CSV、标签表及原 manifest 都校验既有 SHA-256。
- 旧 **30 prompt / 540 行最终留出已经使用**，本轮没有最终留出评估、全量训练、公开测试预测或 Kaggle 提交入口。旧 search/finalize 不执行。
- 在开发子集上固定 `sklearn.model_selection.GroupKFold(n_splits=5, shuffle=False)`，各方案同折。词表、IDF、缩放仅在训练折拟合。
- 这是见过历史最终结果之后的新开发探索，**不产生新的独立泛化估计**。不能和历史自定义分组五折的 0.346818、队友 150-prompt CV 或公榜成绩直接比较。
- 新 OOF 绑定有序 ID、原始行号、标签顺序、fold、输入/配置/源码 hash，保存完整概率并检查有限值、归一化和覆盖。持久 claim 在拟合前占用预算，不能通过换输出目录重置本轮。

## 预先固定的配置与预算

最多四个基础配置，每个五折，**20 次真实拟合**：

| 配置 | 定义 |
|---|---|
| original_style | 原冻结 `b316d0a5c48a`，char (2,5)、大小写保留、100k 上限、26 文体特征权重 0.25、LR C16、无 class weight |
| team_charword | 队友 `char25` + `word12`，原 BLOCK_DEFS，LR C16、balanced |
| team_char13 | 队友 `char13`，LR C4、balanced |
| team_fp | 队友逐文本指纹，折内 StandardScaler，LR C0.25、balanced |

只比较六个事先声明的概率平均：original_style 分别与每个队友视图融合，队友权重 **0.25 / 0.5**。不贪心搜索、不按类别调权、不按公榜选模型；这六次比较均不新增拟合。它们和四个单模型的比较仍有开发选择偏差。

分类器最多 3,000 次迭代（原冻结模型保持原 1,000），CPU 数学库限制两个线程；总墙钟最多 30 分钟，2.5 GiB RSS 检查在每折结束执行（非操作系统硬内存上限）。记录收敛警告、实际拟合数、耗时及峰值 RSS。遇到数值错误、预算或收敛问题停止并报告，不扩展搜索空间。

报告总体 balanced accuracy、各折分数、18 类 recall；以 prompt 为单位做 2,000 次配对 bootstrap，给出对 original_style 的差值与描述性 95% 区间。区间没有对多重比较/历史选择校正，不可标为独立显著性检验。

采用门槛预设为：平均 BA 至少 +0.005、配对区间下界 > 0、五折至少四折提升、无收敛警告。若未达到，本轮工程停止，保留旧冻结交付，不称性能平台期。若达到，仅登记开发候选；本计划仍在 20 次拟合后结束，后续需要新的独立证据，不能借旧留出确认。

配置、输入、分折、融合比例与采用门槛不变。预算**一次性增加1次，总计21次真实拟合尝试**，包括已消耗的失效首折和原定20次有效拟合；总耗时保留失效尝试8.958秒，恢复运行的墙钟上限扣除该耗时。恢复只允许该确切首折失败、0个已验证fold、没有OOF产物、没有先前恢复记录；原failed claim、配置、contract、源码快照原样保存，新结果放在 `recovery_01/`，共享claim从attempted_fits=1继续。不能用于恢复已评分的选择、修改模型或再次扩预算。旧30-prompt留出及其claim不变。
