## 仅三个预定模型

共同特征：训练折拟合TF-IDF，char_wb(2,5)最多100,000维、word(1,2)最多60,000维，后者权重0.5；lowercase=True、min_df=2、sublinear_tf=True、float64，拼接后逐行L2归一化。词token pattern为 `(?u)\b\w+\b|[^\w\s]`。这沿用队友中心化思路但降低词表上限，不冒充原脚本配置复现。

三个配置仅差组均值减去的比例λ：**0、0.5、1**。λ=0为同特征对照。多行组执行 `normalize(x - λ × group_mean)`，单例保留原归一化向量。分类器固定 LogisticRegression(C=16, class_weight=balanced, max_iter=3000)，不搜C或重新选择epoch。

训练侧均值用训练prompt_id。验证侧聚类函数只收文本和ID，不收真实prompt_id、model标签或真实组数：按ID排序后，验证批自身word(1,2) TF-IDF、min_df=1、英文停用词、sublinear_tf、最多60,000维；余弦距离 average-linkage 聚类，固定distance_threshold=0.65，不指定簇数。零向量各自单例。此阈值是预先选择的探索设置，**没有声称已验证最优**。不按n/18推算组数，不做一组18类的硬分配。

验证文本共同参与无监督聚类，因此这是批量转导推理。预测完成后才用真实prompt_id报告ARI/簇大小，不能据诊断回调阈值。

## 固定融合和部署压力检查

三个新模型各与原style概率作新模型权重0.25、0.5的固定平均，共9个候选（3单模型+6融合），不贪心选权重。每个均报告相对原style、相对同权重λ=0对照的差异。

1. 每折按SHA-256(ID)排序保留前一半（向上取整），只用保留文本重新拟合聚类词表、重新聚类和中心化；不读取真实prompt来采样。用完全相同的保留行与原style比较。

这两种压力检查检验对完整批次的依赖，不代表所有隐藏测试组成；不能用它们代替独立验证。原style逐行预测不依赖批次，故原OOF可直接取对应行。
