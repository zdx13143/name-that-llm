# 独立 CPU 实验的原定方案与停止标准

本文件摘录原仓库 `9d293904365f54acdfaa22775c0647d080d1b062` 的 Name That LLM 计划，保留执行前的批次设计供审查。2026-10-18 三轮和一次最终留出已经完成；2026-10-21 只做上传，以下不是重跑指令。实际命令和结果见 [CPU_RESUME](CPU_RESUME.md)与[结果报告](../reports/CPU_EXPERIMENTS.md)。

## Name That LLM

1. 审计真实 `train.csv`、`test.csv`、`sample_submission.parquet`，核对 ID、标签、prompt、重复文本、文件哈希。仅凭网页描述不能冻结最终数据方案。
2. 按 `prompt_id` 分组；发现跨 prompt 重复文本时，先决定去重或合并相连分组，避免重复内容跨集合。暂定预留 20% prompt 组作最终留出集，其余作固定 5 折 group CV。实际审计后确认各折覆盖全部标签；种子暂定 `20261018`。冻结后不通过换种子追求高分。
3. 首批 CPU 基线：字符 TF-IDF（保留大小写/标点）和词 TF-IDF 分别搭配线性 SVM；仅在每折训练集拟合词表、IDF。用 balanced accuracy 比较，记录各类 recall、折间波动、训练/推理时间和内存。
4. 本轮最多 4 批、20 个配置、100 次折内拟合：3 个字符/词/组合基线；基线前两种表征的 `C∈{0.25,1,4}` 与类别权重比较（最多 10 个新增）；4 个单因素消融；3 个逻辑回归配置。另允许预先固定的另外两个开发分组种子复核前两名，最多 20 次额外拟合。CPU 训练墙钟预算 2 小时；到限标为预算边界，不能宣称平台期。新增方向不能重置本轮计数。
5. 先按固定开发折挑选模型。若 CPU 结果仍显示明确改进空间，可在核对可用免费 GPU、具体公开编码器许可及离线依赖后提出补充 GPU 方案；该未指定的模型架构不包含在本轮 CPU 方案批准中。
6. 最终方案冻结后仅评估一次最终留出集，随后在全部允许的训练数据上拟合交付模型。最终留出结果不再用于本轮调参。形成支持任意测试行数的离线 Notebook 和输出校验，正式比赛提交另需明确授权。

## Name That LLM 第二轮 CPU 扩展（2026-10-18，自主决定）

首轮 20 个主配置已完成，暂时最佳开发 balanced accuracy 为 0.295880，首轮预定稳定性复核仍在执行；30 个 prompt 的最终留出尚未打开。当前已证明本机可低成本执行这些模型，因此在冻结最终模型前，追加以下未被首轮充分覆盖的方向。此决定不依据最终留出或公开 test 得分。

| 批次 | 预先固定的新增配置 | 主要问题 |
|---|---|---|
| 文体统计 | 字符 incumbent 加文本长度、标点、空白与格式等确定性数值统计，缩放权重 0.25 / 1 / 4，共 3 个 | L2 TF-IDF 未显式保留的绝对长度/格式是否有效 |
| 字符范围 | char (1,3)/(2,3)/(2,4)，char_wb (2,4)/(3,5)/(4,6)，共 6 个 | 更短片段或词内边界特征是否改善跨 prompt 识别 |
| 分数融合 | 当前字符 incumbent 与词 SVM 独立拟合；每行 decision score 做 L2 归一后，字符权重 0.25 / 0.5 / 0.75，共 3 个 | 两种独立模型是否提供互补预测 |

- 共 12 个新增配置、最多 55 次主分类器拟合：前两批 9×5=45 次，融合三种权重共用每折同一对模型，只做 10 次。另允许本轮最强新候选与首轮 incumbent 在预定两个种子上比较，最多 20 次稳定性拟合；融合胜出时复用其字符 component，保持上限。拟合数与配置评估数分别记录。
- 增量墙钟上限 30 分钟。累计保留首轮 20 配置/100 主拟合/20 稳定性拟合记录，不通过新目录重置历史成本或把预算上限当成平台期。
- 与首轮共用同一冻结 split manifest、同一开发样本和两个预定稳定性种子。数值特征的缩放参数只在训练折拟合；融合不读取验证标签拟合归一化或权重，权重仅按开发 OOF 比较。
- 保留首轮代码和结果；扩展放独立模块。缓存、选择与最终评估核对代码、数据、标签、split 哈希。全部候选完成后统一选择；只有确认不再继续本轮搜索才打开最终留出一次。
- 沿用增益 0.005、按 prompt 的配对 bootstrap 和稳定性判据。三个方向无确认提升可停止当前搜索，但区间不能排除更大收益时应如实写证据不足；不称全局最优。

## Name That LLM 第三轮 CPU 精调（2026-10-18，自主决定）

第二轮文体统计权重 0.25 的开发 BA 为 0.340799，相对首轮最佳增加 0.044919，按 prompt 配对 bootstrap 95% 区间 `[0.029630, 0.059815]`，五折均改善，仍未使用最终留出。因新增方向仍有明显收益，不能在第二轮预算结束时称平台期。追加如下固定范围：

1. 保持第二轮字符 `(2,5)` / LR `C=4`，文体统计权重比较 `0.05/0.1/0.5`，与已有 `0.25` 一同选择。
2. 使用上述最佳文体权重，LR 正则化比较 `C=0.25/1/16`，已有 `C=4` 结果保留作 incumbent。
3. 使用当前最佳文体权重和 LR，比较字符 `(1,3)`、`(2,4)`；另在当前最佳文体/字符范围下测试 LinearSVC `C=1`，共三个配置。

最多 9 个新配置 / 45 次主拟合，另 20 次预定分组稳定性拟合，增量墙钟最多 30 分钟。若与已有配置完全相同则复用已验证的 OOF，不重复训练或虚增新配置数。累计历史成本，使用同一 split/数据/标签版本；保留旧轮代码与结果快照。除逐批比较外，必须比较第三轮最终最佳与第二轮 incumbent 的累计增益，避免把多次微小改善误当成总收益为零。最终留出继续关闭，待当前搜索范围收益判断及代码审查完成后一次性评估。

## 已采用的停止边界

确认提升须开发 BA 增益至少 0.005、按 prompt 配对 bootstrap 区间支持正值并满足折间稳定性。三个不同批次均无确认提升时，可工程停止；区间仍允许较大收益时不得称平台期。预算到限和平台不可访问也不是收敛证据。保留累计配置/拟合/资源记录，不换目录清零。最终留出只在冻模后评分一次，现已完成，不得用于继续选模。
