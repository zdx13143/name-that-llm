## 唯一假设与固定模型

外部数据数量远大于官方训练数据，且API设置、标点与长度有分布差异。提高官方样本损失权重可能改善对比赛分布的适应。固定对照：官方=1、外部=1；唯一候选：官方=4、外部=1。每折共享四组TF-IDF，分别拟合两次LinearSVC。两组都设`class_weight=balanced`；当前scikit-learn 1.7.2会按sample_weight计算有效类频率，因此类权重随样本重加权相应变化，这是候选定义的一部分。其余参数相同。

四视角沿用参考：字符3–5/250k/权重1，词及标点1–3/180k/.7，大小写形状2–6/60k/.5，功能词1–3/50k/.5；min_df=2、sublinear_tf、保留大小写、float32。SVC C=.5、max_iter=5000、random_state=42、dual=auto、tol=1e-4。预测为margin argmax；softmax仅用于保存统一OOF格式，不声称校准概率。不加入温度搜索、融合、题组推断、Sinkhorn或Hungarian。
