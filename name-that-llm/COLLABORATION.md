# 本模块协作约定

遵循仓库根 [README](../README.md#协作约定)：实验分支用 `exp/<主题>`，提交说明包含改动及 CV 影响；报告给出每类召回和对应命令，验证必须按 prompt 分组，不能用随机行切分或公榜调参。当前分支为 `exp/cpu-stylegram-handoff-20261021`。

本次仅导入已有结果，CV 不发生变化。120-prompt 开发与 30-prompt 留出保持历史证据，不能直接和队友的全量五折 CV 或榜单数字比较。未来若要使用队伍当前 GroupKFold 协议，须独立定义新实验，不能把本次已有分数换标签当成同协议重跑。

本模块单独管理依赖，不修改仓库根 requirements、现有模型或队友实验记录。用明确路径暂存，先检查 diff；只推自己的分支，不向 main 或队友分支推送、不强推、不自动合并。数据、凭据、环境、权重和本地输出均不提交。Git 上传不等于 Kaggle Notebook 更新或正式比赛提交。
