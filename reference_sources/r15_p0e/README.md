# P0e generic-base metadata

The `qwen3_8b_base` directory contains only official repository metadata,
the pinned configuration and model card for Qwen/Qwen3-8B-Base revision
`49e3418fbbbca6ecbdf9608b4d22e5a407081db4`. See its
[source index](qwen3_8b_base/source_index.json) for URLs, sizes and SHA256.

This is a generic base candidate for the distinct R15 nested reconstruction,
not proof of the unspecified base revision in the original Kaggle S7 job.
No weights or tokenizer payload were downloaded. The upstream model card
declares Apache-2.0; the license text already archived with the S7 source is
[available here](../r15_p0/LICENSE-2.0.txt).
