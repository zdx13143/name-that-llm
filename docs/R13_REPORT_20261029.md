## Implemented behavior

`experiments/r13_runtime.py` records a unique run ID, UTC timestamps, monotonic elapsed time and four stages: complementary process, complementary output validation, main inference, submission validation. While a child is quiet it emits a heartbeat every 60 seconds. It forwards child stdout/stderr and stores only recognized milestone identifiers/counters in structured events, including adapter completions and ATLAS selected-row counts. It does not estimate percentage complete from those messages.

Each run gets its own `runtime_traces/<run_id>/events.jsonl` and atomic `status.json`. Nonzero exit codes, process launch errors and validation failures leave a failed-stage receipt and propagate the error. There is no retry or time-based termination. `pipeline_validated` requires all four stages in order plus a successful identity check; `placeholder_only` explicitly denotes a normal save. Every receipt keeps `public_score=null` and `external_scoring_verified=false`.

Independent review identified an inherited weakness in R12's final check: row count, unique IDs and non-null model values alone could accept the wrong ID sequence or an invalid label. R13 now checks the expected ID sequence and the exact 18-label set extracted safely from the frozen inference source. Exact order is a consistency requirement of this recipe, not a claim that Kaggle forbids reordered submission files. The checks cannot detect an otherwise valid but inaccurate prediction.

`scripts/build_r13_observed.py` embeds the standard-library observer into a new notebook, wraps only the two checked subprocess calls and output checks, and emits a reproducible manifest. `gauss.py`, `infer.py` and `comp_stack.py` remain byte-identical to R12. Removing the added observation/validation calls and context wrappers reproduces the original launcher AST, including all command arguments and budget arithmetic. The candidate's Kaggle metadata equals the R12 metadata; the candidate has no execution outputs.
