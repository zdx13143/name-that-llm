## Interpretation

- Using the panel structure is by far the strongest lever found so far: +0.061 BA over R16 and
  +0.027 over R22. The true-group oracle at 0.633 shows a lot of remaining headroom from better
  clustering.
- Assignment by itself does not fix the two weak classes:
  - gemini-3.7-flash, the R21 problem, barely moves and is still infeasible for α ≤ 0.5.
  - claude-fable-5 gets worse once α ≥ 1.
- A natural next hypothesis is assignment combined with the R22 3.8→3.7 pair rule, or with a
  per-class prior for fable. It needs its own preregistration. The same 120 prompts now inform
  R19–R24, so cumulative selection bias keeps growing; any next round should say so plainly.
- No submission and no deployment package in R24.
