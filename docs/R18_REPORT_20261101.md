R18 每个 adapter 从同一个固定输入重新加载底模，只合并一次，完成预测后释放。
其余 head、平均、tokenizer、排版强度 0.5、模型权重、30 项输入完全保持。
COMP 与 Gaussian 脚本逐字一致。已知缺失的 main.ll8v5 与 comp.lora24_public 保留，
没有把这轮称为完整集成。adapter 内部的 BF16 重试仍沿用基线。

增加真实模型生命周期日志、8 小时完整 Python 截止、COMP/主成员/ATLAS 完成门槛。
普通 Save 用两段人工文本预检 Qwen 两组共 12 个 adapter，要求 T4 x2、GPU 常驻参数、
相同的底模抽样 fingerprint、释放后无新增大块 Torch 显存、有限的 (2,18) 输出。
Save 总预算为 15 分钟，成功后才生成三行 placeholder；它不是准确率验证。
