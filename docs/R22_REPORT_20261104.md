## Caveats

- The class pair was found from diagnostics on this same 120-prompt development set, and the set
  has been reused across rounds, so selection bias exists.
- λ is cross-fitted on fixed OOF scores. This is not fully nested CV starting from training:
  upstream models in the other folds have seen the outer-fold labels.
- The bootstrap does not account for uncertainty from re-selecting λ.
- The post-processing changes predicted class counts, so the Sinkhorn marginals no longer hold
  exactly.
- The chosen λ is stable (1.0 in 4/5 folds), which supports using a fixed **λ = 1.0** for any
  future submission.
